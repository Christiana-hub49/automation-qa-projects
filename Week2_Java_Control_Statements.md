## Week 2: Control Statements in Java

This week, I learned how to use control statements in Java to make decisions in a program.

---

###  Topics Covered
- If statements  
- If-Else statements  
- Nested If statements  
- If-Else-If statements  
- Switch statements  

---

###  Key Learnings
- The `if` statement runs code only when a condition is true  
- The `if-else` statement handles two possible outcomes  
- The `if-else-if` statement checks multiple conditions and stops at the first true condition  
- Nested `if` statements allow checking conditions inside another condition  
- The `switch` statement is used for selecting from fixed values  
- The `break` keyword prevents execution from continuing to the next case  

---

###  What I Now Understand
- How to evaluate conditions as true or false  
- How Java executes code based on decision-making  
- The difference between `if-else` and `switch`  
- When to use each control statement  

---

###  Reflection
Initially, I found control statements confusing, especially nested `if` and `switch` statements.  
After practicing and breaking them down into simple steps, I now understand how Java processes conditions and makes decisions.
