This week, I learned how to use control statements in Java to make decisions in a program.

 Topics Covered
if statements
if-else statements
nested if statements
if-else-if statements
switch statements

Key Learnings
The if statement runs code only when a condition is true.
The if-else statement allows two possible outcomes.
The if-else-if statement is used to check multiple conditions, and Java stops at the first true condition.
Nested if statements allow checking a condition inside another condition.
The switch statement is used when selecting from fixed values.
The break keyword in a switch statement prevents execution from continuing to the next case.

What I Now Understand
How to evaluate conditions as true or false
How Java executes code based on decision making
The difference between if-else and switch
When to use each control statement

 Reflection
Initially, I found control statements confusing, especially nested if statements and switch statements.
After practicing and breaking them down into simple steps, I now understand how Java processes conditions and makes decisions.
