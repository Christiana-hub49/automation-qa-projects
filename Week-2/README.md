# Week 2: Java Control Flow & OOP Basics

This week focuses on understanding how Java controls the flow of a program using conditions, loops, and introduces Object-Oriented Programming (OOP) concepts.

---

## Topics Covered

### Control Flow

- Loops (for, while, do-while)

### OOP Basics
- Classes and Objects
- Methods in Java
- Variable Scope
- Constructor Overloading
- Inheritance
- Method Overriding
- Polymorphism
- Abstraction
