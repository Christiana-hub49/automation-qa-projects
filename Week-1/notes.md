## My Understanding
Java is a programming language used to build applications and automation scripts.

Variables are used to store data, and data types define the type of data a variable can hold.

Operators are used to perform operations like addition, subtraction, comparison, etc.

## Examples of Data Types
- int → whole numbers
- double → decimal numbers
- String → text
- boolean → true/false
