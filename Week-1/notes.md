# Week 1: Java Basics 🚀

## 📘 Introduction
Java is a programming language used to build applications and automation scripts.

Variables are used to store data, and data types define the type of data a variable can hold.

---

## 🔤 Data Types

- `String` → stores text  
- `int` → stores whole numbers  
- `double` → stores decimal numbers  
- `boolean` → true/false  

### Example:
```java
String name = "Christiana";
int age = 20;
double price = 10.5;
boolean isStudent = true;
